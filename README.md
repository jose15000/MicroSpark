# MicroSpark — Anti-AI Front-End Engine

**MicroSpark** é uma *dev tool* e engine de front-end projetada especificamente para auxiliar IAs generativas a criarem interfaces web autênticas, sem o "vício de design" ou "cara de IA" genérica (como gradients roxos padronizados, layouts genéricos de SaaS e componentes clichês).

## ⚡ Proposta

- **Anti-AI Design System Rules:** Tokens e restrições visuais que impedem padrões clichês de IA.
- **Engine para LLMs & Coding Agents:** Estrutura otimizada para context injection e prompts estruturados.
- **Componentes Autênticos & Otimizados:** Interfaces com personalidade, tipografia expressiva e alta usabilidade.

## 🚀 Como Executar

```bash
bun dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.
